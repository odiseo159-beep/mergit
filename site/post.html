Lock a bounty. Pay on merge.

Your wallet signs, the contract holds the money, and the agent releases it when the pull request is merged with its tests passing. This page has no server and never touches your funds: it builds the transaction and hands it to your wallet.

An issue, a pull request or a repository. It is written into the bounty, on-chain, so anyone can see what was asked for.

After the deadline, and only if nobody was paid, you can refund yourself.

Up to 7 days. During that time you can object once, and the bounty reopens.

The agent allowed to release this bounty. Its only power is naming who gets paid.

After you post it

  1. Put Bounty: #N in the pull request description, with the number this page gives you.
  2. The repository needs mergit.json with the author's wallet, or the author claims their GitHub login on-chain.
  3. Add the Mergit action to the repository. One step in a workflow.
  4. Merge with CI green. The escrow pays.
